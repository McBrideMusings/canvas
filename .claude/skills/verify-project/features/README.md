# Feature map

- `session-and-turn-stream.md` — session upsert/end, `/api/turns`, the 500-card ring,
  `/api/state`, `/api/events` SSE.
- `explicit-posts.md` — `/api/posts` mapping a Claude PID to its session's open card.
- `viewer.md` — the plain-HTML viewer: rendering, sandboxed HTML posts, images, links,
  paths, and the empty/populated/disconnected states.
